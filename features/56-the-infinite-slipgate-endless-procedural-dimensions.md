# 56. The Infinite Slipgate — Endless Procedural Dimensions

> Finish level 8 and the slipgate just keeps opening — onto rooms no one built, forever.

**The idea** — Step through the final exit and the campaign doesn't end: the slipgate disgorges a *ninth* dimension, then a tenth, then on without limit. A seeded generator stitches rooms, corridors, stairs, locked doors and hazard volumes into a coherent map, dresses it in a rolling theme, fills a spawn plan that scales with depth, and hands you the same Silver-Key→door→exit loop you already know. Each dimension is deterministic from `depth + run_seed`, so a run is a reproducible thread of never-before-seen levels. There is no win screen past level 8 — only how deep you got before the floor swallowed you.

**Why it's fresh** — Quake's slipgate was always the promise of *somewhere else*; this finally makes good on it endlessly, without losing the hand-authored brush feel because the generator emits the same brushes the campaign does. Roguelike FPSes randomise arenas and shed authorship; here the generator speaks the level designer's own vocabulary — real corridors, real stairs, real key-gates — so procedural rooms read as *built*, not noise. The campaign becomes a tutorial for an infinite back half.

**How it plays** — The familiar loop turns into a survival-routing ladder: every dimension you clear ratchets the spawn budget and tightens the ammo, so weapon-carry hoarding and clean movement compound into how far you reach. You learn to read an *unseen* layout fast — scan for the key's guard, the locked door, the exit, route between them under pressure. Death is the leaderboard; depth is the score, and the run-seed lets you swap a fatal one with a friend.

**How it fits QUAKECLONE** — This is almost free because `level.rs` is *already* a programmatic `Build` API (`room`, `corridor_z`/`corridor_x`, `stairs`, `door`, `hazard`, `monster`, `item`, `light`) plus a `Theme` registry and a level dispatch — so the generator simply *calls* `Build` instead of a hand-written `levels/levelN` module, and inherits world-aligned UVs and `WorldColliders.solids` collision for nothing. `gamestate.rs` already drives the key→door→exit objective and carries weapons/ammo/health/armor across chained levels, so its `exit_system` just dispatches to "generate the next one" past level 8 rather than the win state. `hud.rs` reuses the per-level banner for a depth counter, `monster_model.rs` and `pickups.rs` skin the placed entities, and `QC_LEVELSHOT` becomes the sanity check that every generated map renders solid and reachable. It composes with the Daily Dimension shared seed and Sigil Pact escalation already on the board.

**Build sketch** — A `gen.rs` lays a graph of room nodes joined by corridors and stairs, picks one node for the exit, gates the path to it behind a door, and drops the Silver Key on the *reachable* side; a seeded PRNG over `depth` makes it deterministic, and the active `Theme` rotates per depth. The honest hard part is *always-solvable, never-degenerate* geometry: no key sealed inside a brush, no exit behind an unopenable door, no room overlapping another — so the generator carves on a coarse grid with reachability + overlap asserts and an automated `QC_EXIT_RUSH`-style sweep over the first hundred depths.

**Effort** — **L.** Main risk: guaranteeing every generated dimension is reachable and non-degenerate, even though the `Build` API hands you texel density and collision correctness for free.
